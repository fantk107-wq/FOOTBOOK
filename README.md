# ⚽ FOOTBOOK

Marketplace mobile de réservation de terrains de football à Itaosy, Madagascar.

## 📱 À propos du projet
FootBook permet aux joueurs de rechercher et réserver des terrains, et aux propriétaires de gérer leurs infrastructures.

## 🛠️ Technologies utilisées
- **Mobile :** React Native, Expo, React Navigation
- **Backend :** Node.js, Express.js, API REST
- **Base de données :** SQLite
- **Outils :** Git, GitHub, VS Code, Postman

## 📂 Structure du projet
- `mobile/` : Application mobile (React Native)
- `backend/` : Serveur API (Node.js/Express)
- `docs/` : Documentation et notes du projet
